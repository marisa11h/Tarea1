# Documentación del proyecto

## Introducción

Este proyecto utiliza GitHub Actions para automatizar tareas de comprobación y documentación.

El repositorio contiene archivos de configuración, documentación general y tres acciones locales implementadas con diferentes tecnologías.

## Objetivos

- Organizar la documentación del proyecto.
- Automatizar la generación de documentación con GitHub Actions.
- Facilitar el mantenimiento del proyecto.
- Documentar el funcionamiento de las acciones locales.

## Tecnologías utilizadas

- Git y GitHub.
- GitHub Actions.
- JavaScript y Node.js.
- Docker.
- Bash.
- MkDocs.

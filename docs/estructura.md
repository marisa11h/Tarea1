# Estructura del proyecto

## Archivos principales

| Archivo o directorio | Descripción |
|---|---|
| `README.md` | Presentación del proyecto. |
| `CONTRIBUTING.md` | Normas para contribuir. |
| `CHANGELOG.md` | Historial de cambios. |
| `LICENSE` | Licencia del proyecto. |
| `SECURITY.md` | Información sobre seguridad. |
| `.gitignore` | Archivos excluidos de Git. |
| `.env.example` | Ejemplo de configuración. |
| `requirements.txt` | Dependencias de Python. |
| `docs/` | Documentación del proyecto. |
| `.github/workflows/` | Workflows de GitHub Actions. |
| `.github/actions/` | Acciones locales del repositorio. |

## Organización

La documentación se encuentra en `docs/` y se genera como un sitio web HTML mediante MkDocs.
